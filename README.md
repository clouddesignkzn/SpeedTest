# Тест скорости скачивания

Консольный скрипт последовательно скачивает указанный HTTP(S)-ресурс 10 раз, дожидаясь полного получения каждого ответа. Затем он показывает среднее время запроса, общий объём данных и скорость скачивания.

## Требования

- Python 3.9 или новее
- Доступ в интернет

Дополнительные библиотеки не нужны: скрипт использует только стандартную библиотеку Python.

## Запуск

```bash
python speed_test.py https://example.com/large-image.jpg
```

В Windows также можно использовать:

```powershell
py speed_test.py https://example.com/large-image.jpg
```

В качестве адреса лучше указать стабильный файл достаточно большого размера, доступный по HTTP или HTTPS. Например, это может быть тяжёлая картинка или архив.

## Запуск из BAT-файла

Можно запускать тест двойным щелчком по `run_speed_test.bat`. Перед запуском нажмите файл правой кнопкой мыши, выберите «Изменить» и вставьте прямой адрес картинки в строку:

```bat
set "URL=https://example.com/large-image.jpg"
```

Сохраните файл и запустите его. Используйте прямую ссылку на файл изображения, а не страницу просмотра или поиска.

## Результаты и единицы измерения

Скрипт выводит:

- среднее время одного полного запроса в секундах (`с`);
- общий объём данных в десятичных мегабайтах (`MB`, где 1 MB = 1 000 000 байт);
- скорость скачивания в мегабайтах в секунду (`MB/s`);
- скорость скачивания в мегабитах в секунду (`Mbit/s`).

Итоговая скорость скачивания считается как общий объём скачанных данных, умноженный на 8, делённый на суммарное время всех 10 загрузок. Каждый запрос выполняется последовательно, а измерение включает получение полного тела ответа.

## Ограничения

Тайм-аут одного запроса составляет 60 секунд. При ошибке HTTP, сетевой ошибке или тайм-ауте скрипт завершает работу с сообщением об ошибке.
